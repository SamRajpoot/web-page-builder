# 🎨 Web Page Builder

A comprehensive, visual drag-and-drop web page builder that enables users to create responsive websites without coding knowledge. Built with React, featuring real-time preview, component management, and clean code export.

## ✨ Features

### Core Features
- **Drag & Drop Interface** - Intuitive visual page construction
- **Component Library** - Text, Image, Button, Input, Container, Video, Tabs, Accordion
- **Real-time Canvas Rendering** - See changes instantly
- **Component Configuration Panel** - Edit properties, styles, and content
- **Layers Panel (DOM Tree)** - Hierarchical view with drag-drop reordering
- **Undo/Redo System** - Full history stack implementation

### Advanced Features
- **Templates & Sections** - Save and load predefined layouts
- **Live Preview Mode** - Toggle between edit and preview modes
- **Responsive Design** - Preview and configure for Desktop, Tablet, Mobile
- **Export & Embed** - Generate clean HTML/CSS code and embed snippets
- **Performance Optimization** - Virtualization for large page structures

## 🚀 Quick Start

### Prerequisites
- Node.js 16+ 
- npm or yarn

### Installation

```bash
# Clone the repository
git clone <repository-url>
cd web-page-builder

# Run the setup script
chmod +x setup.sh
./setup.sh

# Start development server
npm run dev
